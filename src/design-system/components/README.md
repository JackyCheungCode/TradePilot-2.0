# Carbon component catalog

Each control family has a dedicated local entry directory. These modules re-export official Carbon React components and types; they do not copy or imitate Carbon implementation code. Use the component barrel for common imports or a specific folder entry when a narrower import is preferable.

Before adding or changing an export, verify it exists in the installed `@carbon/react` version and preserve the Carbon component's keyboard, focus, semantic, and accessibility behavior. Avoid experimental/unstable APIs unless explicitly approved.
