# TradePilot

TradePilot is a global trade intelligence and business operations workspace.

## Standalone developer handoff

If you want to create an independent installation for your own organization, start with [the standalone developer handoff guide](standalone/README.md).

Each installation must use its own GitHub repository, Supabase project, Cloudflare account/resources, API credentials, and deployment secrets. Do not reuse another installation's production resources.

## API attribution

World time data in Trade Tools is provided by [Time.Now World Time API](https://time.now).
