# TradePilot 系统操作手册（中文）

> 版本：TradePilot 2.0 · 文档基线：当前 `develop` 路由与页面实现  
> 适用对象：销售、外贸业务、运营、管理人员及系统管理员  
> 说明：本手册按当前系统已登记的页面、路由和可见功能整理。不同账号的权限、数据量、外部服务连接状态会影响实际可用操作。标注“需配置/视连接状态”的功能，必须先完成对应配置；“即将开放”不代表当前可操作。

---

## 1. 系统概览与使用原则

TradePilot 是面向外贸业务的工作平台，覆盖全球潜客发现、线索与客户管理、客户沟通、销售机会、报价与订单、贸易单证、发运、收款，以及 AI Agent 和系统配置。

### 1.1 推荐业务主流程

1. 配置企业资料、产品资料、业务规则及外部 API。
2. 通过全球潜客发现获取目标企业线索，或手动录入线索。
3. 在潜客数据中检查来源、评分和企业信息，将合适记录送入 CRM。
4. 在商机/线索模块持续跟进；建立客户档案和联系人关系。
5. 创建销售机会并推进销售阶段。
6. 根据客户需求制作报价单；客户确认后创建销售订单。
7. 根据订单安排发运，记录运输、包装、跟踪和异常。
8. 登记收款、分配到账款并进行对账。
9. 在贸易单证中心生成、编辑、预览和管理业务文件。
10. 在经营驾驶舱查看业务汇总；通过沟通工作区和小雅辅助跟进。

### 1.2 通用操作原则

- 先确认当前客户、联系人、商机或订单，再执行创建、编辑和确认操作。
- 保存草稿与正式确认/签发不是同一动作；正式操作前核对金额、币种、数量、地址、日期和条款。
- 列表页通常用于搜索、筛选、排序和进入记录；详情页用于查看单条记录及执行后续操作。
- 若页面显示加载失败、权限不足或外部服务不可用，先检查登录状态、权限和系统设置，不要重复提交可能已成功的业务动作。
- 金额优先按页面显示的币种及基础币快照规则理解；未配置汇率的外币不应自行推算为统一金额。
- 重要业务资料应保持来源可追溯，避免重复建立客户、联系人和订单。

## 2. 登录、顶部栏与全局导航

### 2.1 登录

访问系统后进入登录页，按页面提示输入账号凭证。系统可能要求额外验证：
- TOTP 动态验证码；
- 恢复码；
- 已注册设备支持时的 WebAuthn/生物识别验证。

若验证失败，检查验证码时效、设备时间和浏览器兼容性；不要将密码、验证码或恢复码分享给他人。登录会话失效时重新登录。

### 2.2 顶部栏

- **TradePilot 标识**：返回应用主入口。
- **小雅入口**：打开/关闭 AI 助手侧面板；小雅用于辅助分析和任务交互。
- **主题设置**：可选择跟随系统、白色、浅灰、深灰或深色主题。
- **账户菜单**：进入个人设置或退出登录。
- **帮助**：打开本系统中文操作手册页面（帮助中心）。

### 2.3 左侧导航分组

| 分组 | 菜单 | 用途 |
|---|---|---|
| 工作台 | 总览 | 查看经营指标、市场分布、销售漏斗、物流及 AI 运行概况 |
| 情报与商机 | 线索数据、商机 | 管理发现数据及销售线索 |
| 客户管理 | 联系人、客户档案、销售机会 | 维护联系人、企业客户及销售机会 |
| 客户沟通 | 沟通 | 集中处理客户会话与全渠道消息 |
| 贸易业务 | 报价单、销售订单、贸易单证、物流发货、收款管理、产品管理 | 完成外贸交易履约 |
| 设置与系统 | 贸易工具、AI 与 Agent、系统设置、安全中心 | 配置工具、AI 能力、业务规则和安全选项 |

在窄屏设备上，左侧导航会以覆盖层方式展开；选择页面后导航自动收起。

## 3. 工作台：总览（/dashboard）

### 用途
总览汇集客户、联系人、线索、商机、报价/订单、发运、收款、产品和 Agent 运行等数据，帮助管理者了解业务状态。

### 操作步骤
1. 打开“工作台 → 总览”。
2. 等待数据加载；若出现错误提示，先检查网络、登录会话和数据权限。
3. 使用时间范围筛选查看近期、较长周期或全部数据。
4. 使用国家/市场筛选缩小分析范围。
5. 在市场指标切换项中选择要观察的对象，结合地图和图表查看分布。
6. 点击可交互指标或模块入口（若页面提供）进入对应业务记录继续处理。
7. 使用刷新操作重新读取数据。

### 指标理解
- 总览是聚合视图，不代替业务模块中的单据详情和财务核对。
- 客户、线索、商机、订单等统计口径取决于记录状态及筛选条件。
- 外币金额只有在记录存在可用基础币金额快照时才可纳入统一金额汇总；未配置汇率的外币不参与合计。
- Agent 运行数量不等同于已完成的业务成果，需结合任务状态和结果明细判断。

## 4. 全球情报与线索管理

### 4.1 全球外贸智能潜客发现（/prospect-discovery）

该页面采用五步流程：

1. **数据源与平台选择**：选择可用的数据源/平台。数据源是否可用取决于服务接入及账号配置。
2. **动态参数配置**：按所选数据源提供的真实参数表填写搜索条件；不同平台字段可能不同。
3. **执行全网搜索**：核对目标国家、关键词、平台和执行范围后启动任务。
4. **AI 智能清洗与打分**：系统对发现结果进行整理、去重/质量处理和潜客评分；评分仅作筛选辅助，仍需人工判断。
5. **决策人穿透与入库**：查看可获得的决策人/联系人信息，确认后将合适记录纳入后续 CRM 流程。

页面提供“历史任务”和“潜客数据”入口。任务执行可能需要等待外部平台返回数据。

### 4.2 历史任务（/prospect-history）

- 查看历史发现任务、任务编号、搜索条件、渠道、状态和结果数量。
- 状态可能包括排队中、执行中、已完成、部分完成、失败、已取消或已暂停。
- 打开单个任务可查看执行日志和发现结果。
- 若任务部分完成，检查日志及结果后再决定是否调整条件重新执行。
- 重新执行前先检查是否已有相同任务结果，避免重复数据。

### 4.3 潜客数据（/prospect-data）

- 查看从不同来源采集的潜客记录及企业信息。
- 使用搜索、筛选、排序和分页定位目标企业。
- 核对企业名称、国家、网站、联系方式、来源、评分和状态。
- 记录状态可能包括待处理、已送入 CRM、已废弃或手动移除。
- 将合格记录送入 CRM 前，先检查是否已存在相同客户/线索。
- 对无效、重复或不符合目标画像的记录，按页面提供的管理操作处理。

### 4.4 商机/线索（/leads）

- 查看线索编号、企业、国家、联系方式、来源和跟进状态。
- 可通过新建入口手动录入线索；从潜客转入的记录应保留来源信息。
- 按状态推进跟进，例如新建、联系中、已确认、已转换或已失效（具体选项以页面为准）。
- 线索转化前核实企业是否已存在于客户档案，避免重复建档。
- 线索是潜在业务对象；转化为正式客户或销售机会后，应在对应模块继续维护。

## 5. 客户关系管理（CRM）

### 5.1 客户档案（/accounts）

客户档案用于维护企业客户主数据。

**常见流程**
1. 进入“客户档案”，搜索客户名称或使用筛选条件定位记录。
2. 打开详情检查企业名称、国家/地区、行业、状态和关联信息。
3. 新建客户时填写必要企业信息及联系方式；保存前检查重复记录。
4. 在详情页维护客户信息，并查看相关联系人、商机或业务关联（以页面实际展示为准）。
5. 客户状态变化时及时更新，避免将失效客户继续用于新业务。

### 5.2 联系人（/contacts）

联系人是客户企业中的个人联系对象。

**常见流程**
1. 进入联系人列表，按姓名、客户或联系方式查找。
2. 新建联系人时尽量关联正确的客户档案。
3. 填写姓名、职位、邮箱、电话等可用信息。
4. 保存后进入详情核对归属客户和联系方式。
5. 联系人离职或信息失效时，更新状态或资料；不要随意删除仍有关联业务的历史联系人。

### 5.3 销售机会（/opportunities）

销售机会用于管理从需求识别到成交的销售过程。

**常见流程**
1. 创建销售机会并关联客户；如有联系人，选择对应联系人。
2. 填写机会名称、预计金额、币种、概率、预计成交日期和负责人等页面要求字段。
3. 根据实际沟通推进销售阶段，记录下一步行动。
4. 更新预计金额和成交概率时，以最新客户反馈为依据。
5. 成交后按业务流程创建报价单或销售订单；失败机会应更新状态并保留原因。

## 6. 客户沟通与小雅

### 6.1 沟通工作区（/communications）

沟通页面用于集中处理客户会话和全渠道消息。

1. 打开“客户沟通 → 沟通”。
2. 从客户/会话列表选择目标客户。
3. 查看消息历史和上下文，确认沟通对象。
4. 在回复区域撰写消息，核对发送渠道及内容后发送。
5. 需要继续跟进时，结合客户档案、联系人和商机更新业务记录。
6. 移动端可使用客户列表返回入口切换会话。

可用渠道和消息能力取决于已连接的消息服务与账号授权。发送失败时先检查渠道连接状态，避免重复发送。

### 6.2 小雅 AI 助手（顶部小雅入口、/agent）

- 通过顶部小雅入口打开侧面板，或进入 Agent 工作区进行较完整的任务交互。
- 在输入框说明目标、对象、国家/市场、期望结果和限制条件。
- 如页面提供 Agent、执行模式或渠道选择，应在提交前核对。
- 发送后关注任务状态、进度、工具调用结果及错误提示。
- 对 AI 生成的客户信息、市场判断、邮件或建议，必须人工核验后再用于正式业务。
- 不要向 AI 输入密码、验证码、银行卡完整信息或其他不应共享的敏感数据。

## 7. 销售交易管理

### 7.1 报价单（/quotes）

1. 进入报价单列表，搜索或筛选目标报价。
2. 新建报价单，选择客户及相关业务信息。
3. 添加产品/服务明细，核对数量、单价、币种、税费、折扣和总额。
4. 填写有效期、交付/贸易条款及备注等必要信息。
5. 保存草稿后进入详情复核。
6. 对外发送或正式确认前，检查客户抬头、明细、金额和有效期。
7. 修改已保存报价时，留意修订/版本记录及客户确认状态。

报价单详情的历史版本、事件记录可能受数据权限和关联数据可用性影响；若无法加载，先确认主报价记录和访问权限。

### 7.2 销售订单（/sales-orders）

1. 根据已确认的报价或客户订单创建销售订单。
2. 核对客户、产品明细、数量、价格、币种、交付日期及贸易条款。
3. 保存草稿并复核。
4. 按页面提供的确认操作完成订单确认；确认后部分字段可能受到状态规则限制。
5. 后续从订单进入发运、收款和单证流程。
6. 订单取消或变更应遵循企业内部审批规则，并保留原因。

### 7.3 产品管理（/products）

- 产品列表用于搜索、筛选和维护产品主数据。
- 新建产品时填写名称、SKU、分类、品牌、规格、单位及页面要求字段。
- 规格属性、变体和分类等基础字典通常在系统设置中维护。
- 编辑产品前检查其是否已被报价或订单引用。
- 停售/归档与删除含义不同：停售用于停止新业务选用，历史单据仍需保留可追溯信息。

## 8. 贸易单证中心

### 8.1 单证中心（/documents）

单证中心按交易单据、商业单据、物流单据等类别组织制作入口。当前页面列出的首期可用类型包括报价单、形式发票（PI）、销售合同、商业发票、装箱单和装运指示。页面标注“即将开放”的类型尚不可使用。

### 8.2 单证工作台（/documents/studio）

1. 从单证中心选择单据类型，或打开即时单据入口。
2. 选择业务来源（例如订单或发运批次），按页面提示载入数据。
3. 检查企业抬头、客户信息、产品明细、金额、币种、包装和运输信息。
4. 在编辑画布中调整内容与版式。
5. 保存草稿并预览；确认内容无误后再按页面提供的流程生成正式文件。
6. 生成后到“已生成单据”查看记录和历史版本。

### 8.3 模板中心（/documents/templates）

管理预设模板、个人模板和企业模板。选择模板时确认单据类型、语言、品牌信息及展示字段；修改模板前建议保留可复用版本。

### 8.4 企业信息（/documents/company-profile）

维护单据中使用的企业卖方抬头、注册地址、联系方式和收款账户。企业资料发生变化后，应检查新生成单据是否已读取最新资料。

### 8.5 已生成单据（/documents/generated）与预览（/documents/:id）

- 在已生成单据列表中查找草稿、已签发文件及历史版本。
- 打开单据预览，核对页面显示、字段、金额和文件内容。
- 正式文件应按企业文件管理制度归档；不要将草稿误认为已签发文件。

## 9. 物流发运与收款

### 9.1 物流发货（/shipments）

1. 从销售订单或页面提供的业务来源创建发运记录。
2. 填写运输方式、计划发运日期、包装/箱型、数量、费用及跟踪信息。
3. 核对收货方、地址、订单明细和发运数量。
4. 保存后进入发运详情持续更新物流节点。
5. 出现延误、货损或其他异常时，按页面字段记录异常并及时通知相关人员。
6. 需要单据时，从发运详情使用生成单据入口。
7. 编辑或取消前确认发运状态及其对订单、单证的影响。

### 9.2 收款管理（/payments）

1. 创建收款记录，关联客户及对应订单/业务。
2. 填写收款方式、日期、币种、金额、手续费和银行/账户信息。
3. 保存后检查收款详情。
4. 对预收款或未分配余额，进入分配页面（/payments/:id/allocate），选择对应应收业务并核对分配金额。
5. 登记退款时核实原收款、退款金额、日期和原因。
6. 根据银行流水核对到账金额、手续费和实际净收金额。
7. 对账信息保存后复核差异；收款记录不等于银行实际到账，需以银行凭证为准。

## 10. 贸易工具（/trade-tools）

贸易工具中心用于访问外贸工作所需的辅助工具。具体工具是否可执行取决于对应服务、API 凭证和权限配置。

- 先阅读工具说明及所需输入。
- 输入国家、币种、产品、运输或其他参数时核对单位和格式。
- 执行前确认是否会调用第三方服务或产生费用。
- 对工具输出的汇率、时间、运输信息、翻译或市场数据，关注来源和更新时间。
- 工具返回错误时检查 API 配置、额度和参数，不要将失败结果作为正式业务依据。

## 11. AI 与 Agent 管理（/ai-agents）

AI 与 Agent 中心集中管理 AI 模型、Agent、外部 Agent、Skills、Tools、任务调度、安全与历史记录。页面通过 URL 参数选择具体分区，例如 `/ai-agents?section=skills`。

### 11.1 AI 总览与模型/供应商
查看 AI 平台概况并配置可用模型与供应商。使用前确认供应商凭证、模型标识和调用权限；不同模型的能力、费用和可用区域可能不同。

### 11.2 Agent 管理
维护专业 Agent 的定义、启用状态和任务能力。配置变更后应通过低风险任务验证，再用于正式业务。

### 11.3 第三方 Agent 接入
登记外部 Agent 的连接信息和授权范围。只授予完成任务所需的最小权限，定期复核连接状态。

### 11.4 Skills 管理
管理 Agent 可调用的技能定义/资源。注册技能前检查来源、版本、说明、输入输出契约和权限要求；启用后先测试，再开放给业务任务使用。

### 11.5 Tools 管理
管理可供 Agent 使用的工具能力。工具权限应按风险和用途配置；涉及写入、外部发送或费用的工具需特别谨慎。

### 11.6 任务与调度
查看任务执行记录及调度状态。排查失败任务时检查输入、权限、外部服务和执行日志；避免在不清楚幂等性的情况下重复触发写操作。

### 11.7 权限与安全
检查 Agent、Skill、Tool 的授权边界和执行限制。遵循最小权限原则，不要把管理密钥写入技能说明或提示词。

### 11.8 AI 历史记录与小雅形象
查看历史交互和任务上下文；可在支持的设置区调整小雅形象。历史结果仅用于追溯，不能替代业务单据的正式记录。

> 当前页面中“运行监控”区标记为后续接入；不要将其描述为已完整开放的监控能力。

## 12. 系统设置（/settings）

系统设置采用业务领域分组。可用设置以当前账号权限及页面实际呈现为准。

### 12.1 产品设置
- 产品分类与产品线：维护多级分类。
- 规格属性：定义可复用属性。
- 规格模板：按分类组合产品属性。
- 产品变体规则：维护变体组合和 SKU 规则。
- 认证类型：维护 CE、FCC、RoHS 等认证字典。

### 12.2 CRM 设置
按客户、联系人、线索、商机等领域维护业务字段、状态、选项及相关规则。调整前先评估对已有记录、筛选条件和报表的影响。

### 12.3 企业档案
维护企业法定身份、注册地址、联系方式、经营信息、单据卖方抬头和收款银行账户。此处信息可能被单据生成流程调用。

### 12.4 单据配置
- 单据类型管理：配置单据来源、字段校验、编辑权限和正式确认规则。
- 模板管理：按类型和语言管理版式、展示字段及默认模板。
- 通用设置：维护报价单和销售订单共享规则。
- 报价单设置：维护有效期、修订和客户确认规则。
- 销售订单设置：维护确认、锁定、履行和取消规则。

### 12.5 发运与收款设置
- 共享基础设置：币种和贸易术语。
- 发运设置：运输规则、运输方式、箱型、包装、费用、跟踪节点和异常字典。
- 收款设置：收款方式、账户、汇率/手续费、应收账龄、信用证、退款核销和对账规则。
- 部分设置可能仅提供规则配置，并不代表已连接银行或承运商的实时服务。

### 12.6 API 集成
统一维护外部服务凭证和连接信息。保存前核对服务商、环境、权限和额度；密钥仅放在专用安全配置中，不要复制到普通备注或文档。

## 13. 个人设置与安全中心

### 13.1 个人设置（/personal-settings）
管理当前用户的个人资料及可用偏好。修改后检查保存反馈；头像等资料可能来自登录身份提供商。

### 13.2 安全中心（/security）
用于查看和管理账号安全相关能力。系统可能支持 MFA、恢复码及 WebAuthn/通行密钥等验证方式。建议：
- 为账号启用多因素验证；
- 将恢复码保存在安全位置；
- 不与他人共享验证设备或恢复码；
- 更换设备前确认仍有可用的备用验证方式。

## 14. 常见问题与故障处理

| 现象 | 建议检查 |
|---|---|
| 页面提示登录失效 | 重新登录；若持续发生，检查会话和浏览器 Cookie 设置 |
| 列表没有数据 | 清除筛选条件，检查时间范围、国家筛选和账号权限 |
| 数据加载失败 | 刷新一次；检查网络、登录状态及服务状态；保留错误提示 |
| 潜客任务失败/部分完成 | 查看历史任务日志、数据源连接、参数和服务额度 |
| Agent 无法执行 | 检查 Agent 是否启用、模型供应商、Skill/Tool 授权及任务输入 |
| 沟通消息发送失败 | 检查消息渠道是否连接、授权是否过期；先确认是否已发送再重试 |
| 报价/订单金额不一致 | 核对币种、数量、折扣、税费、汇率快照和单据版本 |
| 单证资料不正确 | 检查企业档案、客户资料、来源订单/发运批次及模板字段 |
| 发运/收款信息无法保存 | 检查必填字段、状态规则、关联订单及权限 |
| 页面功能显示不可用 | 检查账号权限、功能状态和对应服务配置；“即将开放”项目暂不可使用 |

向管理员反馈问题时，请提供页面名称、发生时间、记录编号、操作步骤和错误提示；不要发送密码、验证码、访问令牌或完整支付凭证。
